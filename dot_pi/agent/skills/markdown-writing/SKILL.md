# Markdown writing

## Rules

1. Be concise and correct. Cut fluff; every sentence earns its place.
2. Wrap lines at 80 characters. Allow 81+ only for an unwrappable
   file path or link.
3. Avoid tables and ASCII art unless nothing else conveys the meaning.

## Guidelines

- Lead with the point, then support it. No preamble.
- Prefer short sentences and active voice.
- Use one idea per paragraph; keep paragraphs short.
- Favor lists over long prose when enumerating.
- Use headings to structure, not decorate; skip single-item sections.
- Use inline code for identifiers, paths, and commands.
- Prefer a fenced block over a table for structured data.
- Say it once. Drop restatements and obvious caveats.
- Keep terms consistent: define once, then reuse the same name.
- Match the surrounding document's voice and formatting.
