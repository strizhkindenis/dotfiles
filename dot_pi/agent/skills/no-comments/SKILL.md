# No comments

Add no comments: doc, inline, block, or TODO.

Rationale:

1. Stale comments mislead and demand upkeep.
2. Clear code explains itself.
3. Agents infer logic from code.
4. Fewer tokens.

Let names, types, and structure carry intent.
Remove stale comments you touch.
